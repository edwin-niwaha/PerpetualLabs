# Journal samples for Perpetual Labs

Three original editorial drafts with AI-generated photorealistic covers. Added only to the local SQLite journal for review; nothing has been published to the live website.

## Copy to the live site

1. Sign in as an administrator and open **Client portal → Journal → Write an entry**.
2. Copy the title and excerpt below into their respective fields and select or create the category.
3. Open the linked `.md` file and paste its entire contents into the article body. The body uses Markdown; do not paste this instruction document.
4. Upload the matching PNG from `images/` using the cover-image picker. Upload the file itself, not its local URL. This lets the live site's media storage keep the picture across deployments.
5. Review the preview, author, category, and publication date. Save as a draft or publish when ready.

The images are AI-generated, natural-looking editorial scenes with fictional people. They are not photographs of actual Perpetual Labs staff or clients. Suggested alt descriptions are included for any publishing system that supports them. The existing local posts were preserved. Local samples use the existing Admin account as author; choose the intended author when publishing live.

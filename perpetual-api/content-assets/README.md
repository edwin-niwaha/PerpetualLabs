# Website media

Reviewed 25 September 2026. These optimized assets ship with the catalog import command. Uploaded working copies are stored by Django's configured media storage; database fields hold their paths and metadata.

- galaxy.webp: NASA/ESA Hubble photograph of M51. Credit: NASA, ESA, S. Beckwith (STScI), and The Hubble Heritage Team (STScI/AURA). Source: https://science.nasa.gov/asset/hubble/out-of-this-whirl-the-whirlpool-galaxy-m51-and-companion-galaxy/ . Resized and compressed.
- earth.webp: NASA Blue Marble texture. Source: https://visibleearth.nasa.gov/images/57730/the-blue-marble-land-surface-ocean-color-and-sea-ice . Resized and compressed.
- pendeza.webp: screenshot of https://sponsorwithpendeza.org/ in an original decorative browser frame.
- jobell.webp: screenshot of https://jobellinc.com/ in an original decorative browser frame.
- duukayo.webp and fincore.webp: original product illustrations, not screenshots or claims of a live deployment.

The cosmic scene combines real photography with artistic planet animation; it is not an astronomical simulation.

# Perpetual Labs

The Perpetual Labs website and API live together in this repository.

- **perpetual-web/** — Next.js, TypeScript, and Tailwind CSS website.
- **perpetual-api/** — Django REST API for content, accounts, and contact submissions.

Both directories are regular folders; no submodule initialization is required.

See [local setup, environment configuration, and test instructions](perpetual-web/README.md).
